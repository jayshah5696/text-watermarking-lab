Why Stage 3 used MLX, and why Stage 4 changes tools.

This is an average across repeated baseline checks, not a promise.

usual variation = sqrt(39 x 0.25 x 0.75) = 2.7042

z = (17 - 9.75) / 2.7042 = 2.6811

Read the result as a sentence. The green count is 2.6811 usual amounts of variation above the 25 percent baseline. Transformers uses the strict rule z > 3.0. This short continuation falls below that configured cutoff even though Transformers generated it with the watermark turned on. The result is insufficient evidence for this configured watermark and key. It does not prove human origin or absence of a watermark.
