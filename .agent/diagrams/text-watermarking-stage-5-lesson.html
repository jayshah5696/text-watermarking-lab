The reusable path has four jobs.

A compatible model must expose text IDs, a text vocabulary, generation, and continuation decoding. The shared watermark code should not know the model ID or cloud provider.

Compatible does not mean every Hub repository. Encoder-only models, remote APIs that hide logits, and unreviewed custom generation code need another design.

03

The key enters at generation time.

Both calls use the same loaded model, encoded prompt, seed, sampler, device, and token cap. One argument changes.

Control

model.generate( input_ids=encoded.input_ids, attention_mask=encoded.attention_mask, do_sample=True, temperature=0.8, top_k=40, top_p=0.95, )

Watermarked

model.generate( input_ids=encoded.input_ids, attention_mask=encoded.attention_mask, do_sample=True, temperature=0.8, top_k=40, top_p=0.95, watermarking_config=profile.to_transformers(), )
1model logits
2sampling warpers
3watermark processor
4sample one ID
5append and repeat

Watermarked path: Transformers constructs the keyed logits processor and applies it during every next-token decision. The key is not prompt text and is not added after generation.

04

Construct the profile inside the process.

The public key below reproduces this lab. A real service replaces its source, not the watermark API.

key = public_demo_key(value=15485863, version="demo-v1") # hosted service: key = private_key_from_environment( variable="WATERMARK_HASHING_KEY", version_variable="WATERMARK_KEY_VERSION", ) profile = WatermarkProfile( green_fraction=0.25, bias=2.0, hashing_key=key.value, seeding_scheme="lefthash", context_width=1, )
The public demo key provides reproducibility, not secrecy. Anyone who knows it can try to spoof or remove the signal.

Forbidden: key value, secret name, raw environment, internal prompt.

Private mode: the host injects a key at process startup. The response may name a non-secret key version. The key value stays inside the server process.

Replaceable compute: Modal, a VM, Kubernetes, or another GPU provider can run this process. Authentication, rate limits, timeouts, autoscaling, logging policy, and key rotation belong to the host layer.

09

What you still need before a real deployment.

The code boundary is ready for review. Production policy and calibration remain open work.

Implemented here

  • explicit compatible-model adapter contract
  • generation-time key insertion
  • strict assistant-content parsing
  • matching copied-text detector
  • public-demo and server-secret key policies
  • allowlisted request and response records

Still unimplemented

  • authenticated endpoint and deployment
  • secret creation and rotation procedure
  • rate limits and abuse controls
  • production logs and incident policy
  • calibrated detector cutoff and false-alarm rate
  • support for arbitrary model repositories
Provider example: the existing Modal wrapper

The committed wrapper declares Python 3.12, pinned packages, one L4, one container, and the Gemma adapter. Its function receives locked configuration and returns JSON. No endpoint or persistent service was created.

Measured feasibility and cost appendix

For the saved smoke, the model downloaded in 36.739 seconds and loaded in 5.782 seconds. Peak reserved memory was 9.682 GiB of 22.034 GiB. The slowest watermarked rate was 18.422 generated tokens per second. At the recorded L4 price, 9,600 generated tokens project to $0.1157 of GPU generation time. This excludes image build, download, load, CPU, memory, storage, retries, and non-linear scaling. It is not a cloud invoice.
