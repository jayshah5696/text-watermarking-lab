Text watermarking lab / Stage 3

Where does the score change happen?

Stage 2 changed scores that we wrote by hand. Stage 3 uses a real LFM2 model on MLX and leaves the generation loop open so we can inspect every step.

This page shows
A pinned local model run, one explicit score change, seeded sampling, and copied-text checking.

This page does not show
A tested detector cutoff, AI authorship, a private vendor system, or model quality.

What the run supports

In all three fixed pairs, the score-increase continuation has more same-key green hits than its control in this replayable local run.

What it cannot support

Three passages do not measure accuracy, a false-positive rate, prose quality, or a cutoff. No row proves AI origin or authorship.

The complete lesson without animation

  1. The chat tokenizer turns the instruction and passage into 36 model-input tokens.
  2. LFM2 returns 65,536 raw next-token scores.
  3. The generation key marks exactly 25% of token IDs green.
  4. The score-increase path adds 2 before temperature, top-p, and top-k.
  5. The seeded sampler chooses Jack and the loop appends it.
  6. The copied continuation has 21 green hits in 39 eligible positions with the generation key and 7 with the comparison key.
